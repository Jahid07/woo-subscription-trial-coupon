# Security policy

Please report suspected vulnerabilities privately through this repository's GitHub Security Advisories reporting option if enabled. If private reporting is unavailable, use WordPress.org's plugin security reporting process: https://developer.wordpress.org/plugins/wordpress-org/reporting-plugin-security-issues/ . Avoid posting exploit details in public issues.

Public issues are welcome for non-security bugs and compatibility reports. Include plugin, WordPress, PHP, theme, and relevant dependency versions, reproduction steps, and redacted logs.
